# 区域包：熔痕裂谷（Lavarift）

> 危险度：C/B。第二个开放区域，世界的"热伤口"。

## 区域设定

熔痕裂谷在烬炉镇以东一日路程。没有任何铺垫能代替第一眼看见它——大地在这里被整个撕开，裂口最宽处逾百步，深不见底，谷底岩浆像一条缓慢的、暗红色的河。

裂谷不是尤克特拉枯死的产物，它比这更老。矿工们挖出的岩层纹路显示，这片土地在千年前就烧过一场。但近几十年，谷底的光越来越亮，热气一年比一年往上涌——矿工们私下说，"地底下有什么东西在翻身"。

**裂谷的生计**：火纹矿（锻造的上佳辅料，圣辉城骑士团常年收购）、硫磺、耐热晶石。矿工营地扎在裂谷边缘的岩台上，百来号人，三班倒地下矿。营地归圣辉城的矿务行会节制，但实际话事人是矿工头子黛拉。

**灰烬会（只做传闻铺垫）**：矿工间流传着压低声音的警告——裂谷深处有些矿道"不是矿工行会挖的"；有人在夜班时见过岩壁上新鲜的、不属于任何已知商队的标记；丢过矿灯，丢过一整筐火纹矿，但从没人丢过命。"他们不害矿工，"黛拉会说，"他们嫌我们穷。"

## 节点结构

| 节点 | 说明 | 连接 |
|---|---|---|
| 裂谷边缘 | 入口。能俯瞰谷底岩浆河，风是烫的 | 烬炉镇、黑曜石坡道 |
| 黑曜石坡道 | 下矿的主路，两侧是黑色玻璃质岩壁 | 裂谷边缘、矿工营地、熔痕深处 |
| 矿工营地 | 野外落脚点。黛拉，基础补给+本地八卦+本地委托 | 黑曜石坡道 |
| 熔痕深处 | 最靠近岩浆层的矿道群。火属性魔物活跃 | 黑曜石坡道、龙鳞岩台（隐藏） |
| 龙鳞岩台（隐藏） | 发现地点。一片突出的岩台，嵌着一片巨大的暗金色鳞 | 熔痕深处 |

**环境规则**：熔痕深处极热，探索消耗的水加倍（引擎实现）。极寒天气下裂谷反而舒适（黛拉会调侃"好天气"）。

## NPC 卡

### 矿工头子黛拉
- 四十五岁，人类，左脸有一片旧烫伤。下矿二十年，从背矿渣的小工干到管百来号人。
- 功能：野外据点主。基础补给（水卖得比别处贵，"在这儿水就是命"）、本地八卦、本地委托（矿洞塌方救援、火元素异动调查）。
- 性格：话少，评价人只看一件事——"你下不下得来，上不上得去"。玩家在裂谷完成委托后，她会第一次叫玩家的名字而不是"那个冒险的"。
- 八卦：谷底的光三十年前是暗红色的，现在"红得发白"；圣辉城矿务行会的人上个月来测量过，"量完一句话没说就走了"；灰烬会的标记她见过，"像一小撮摆成人形的灰"。

### 老矿工岩叔
- 六十岁，在裂谷挖了一辈子矿，如今看营地、修工具。
- 功能：八卦来源；龙鳞岩台的引路人（委托链后期透露"南边矿道尽头有个怪地方"）。
- 他的规矩：不跟"眼里只有矿"的人说话。

### 被困矿工小燧（事件 NPC）
- 二十二岁，矿洞塌方事件（q_c_collapse）中被困的矿工。
- 获救后会在营地逢人就讲玩家的事（小额声望来源，"事迹驱动声望"的样板）。

## 隐藏地点：龙鳞岩台

- 解锁：熔痕深处触发"龙鳞微光"事件，或完成 q_c_collapse 后由岩叔指路。
- 内容：一片突出于裂谷壁的岩台，岩层里嵌着一片足有桌面大的暗金色鳞片，边缘锋利如新。这是 MVP 里龙"存在过"的最硬证据。
- 规则（冻结）：玩家可以触摸、可以拓印、可以带一小块崩落的碎片回去（高价品/剧情物），但鳞片本体无法取下——任何"挖出整片龙鳞"的申请由引擎驳回。
- 发现后：玛尔塔的大新闻更新（"全镇都在说你在裂谷摸到的那东西"）、dragon_rumor_count +2、芬恩登记为正式事迹（声望 +15）。

## 氛围描写基准（供 LLM 演绎）

裂谷的关键词是"温度与光"。写热：空气的扭曲、汗在脊背上的轨迹、水壶以可见的速度变轻。写光：谷底的红光把每个人的脸映成另一种人。矿工的幽默是干巴巴的、带着硫磺味的幽默。这里比雾帷森林更危险，但也更诚实——威胁都摆在明处。
