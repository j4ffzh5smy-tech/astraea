# 区域包：雾帷森林（Mistwood）

> 危险度：D/C。新手区域，但雾会惩罚傲慢的人。

## 区域设定

雾帷森林在烬炉镇以北半日路程。林子很老——比烬炉镇老，比王国现行的历法也老。尤克特拉死后，大陆的水汽失了管束，这片林子便常年笼在一层化不开的轻雾里。

雾不浓时能看见十步，浓时三步。林中的声音传得古怪：近处的狼嚎听着像在天边，头顶的鸟鸣倒像贴着耳朵。老猎户加洛说，在雾帷森林，耳朵是最会骗人的东西。

森林不是恶意之地。它有药草、有猎物、有月光苔在夜里给赶路的人照亮一小片树根。但它要求来客保持谦逊——走得越急，迷得越深。

**森林里的生计**：烬炉镇的药剂师沿固定的采药小径进出；猎户小屋是猎人们的落脚点；更深处的废弃哨塔是王国旧年边防的遗物，如今已无人记得它的名字。

## 节点结构

| 节点 | 说明 | 连接 |
|---|---|---|
| 林缘小径 | 入口。雾最薄，采药小径的起点 | 烬炉镇、林间空地 |
| 林间空地 | 中心节点。一片晒得到太阳的空地，适合扎营 | 林缘小径、废弃哨塔、猎户小屋、迷雾深处 |
| 废弃哨塔 | 旧边防塔，魔物巢穴。狼王灰鬃的领地外围 | 林间空地 |
| 猎户小屋 | 野外落脚点。老猎户加洛，基础补给+本地八卦+本地委托 | 林间空地 |
| 迷雾深处 | 雾最浓处。走失的孩子、雾行蛛、隐藏地点入口 | 林间空地、月光苔洞窟（隐藏） |
| 月光苔洞窟（隐藏） | 发现地点。洞壁覆满月光苔，药剂师梦寐以求的产地 | 迷雾深处 |

**迷路规则（氛围）**：大雾天气下在节点间移动，有小概率被送回出发节点并触发迷路事件（引擎实现：移动失败+叙事）。加洛的提醒、绳索道具可降低迷路率。

## NPC 卡

### 老猎户加洛
- 六十岁，独腿（年轻时被熊咬的，他坚称那头熊后来"想通了"），住在猎户小屋。
- 功能：野外据点主。基础补给（干粮/净水，品种少于艾达）、本地八卦、本地委托（狼王灰鬃）。
- 他知道森林里每条兽径，但只告诉"走得不急的人"。玩家在他这里停留次数越多，他透露的森林秘密越多（软状态渐进）。
- 八卦：雾帷森林的雾比十年前厚了一倍；他年轻时在迷雾深处见过"一整面会发光的墙"（月光苔洞窟线索）；狼王灰鬃不是普通的狼——"它看你的眼神，像在掂量你是不是值得它费劲。"

### 药剂师学徒青芷
- 十六岁，布罗迪的学徒，每月沿采药小径进林三次。
- 功能：护送委托 q_c_escort 的对象；月光苔洞窟发现后的采集剧情。
- 性格：紧张时话密，崇拜布罗迪，梦想"配出一种能让师父闭嘴三秒钟的药"。

### 走失的孩子小荞（事件 NPC）
- 八岁，烬炉镇农户的孩子，追着"发光的小鹿"跑进森林（委托 q_d_child）。
- 找到他时他正蹲在月光苔洞窟入口附近，毫发无损，坚称小鹿"领他来的，还让他看了会发光的山洞"。
- 这孩子口中的"小鹿"是什么，MVP 不解释。

## 委托/遭遇链

- q_d_wolves（D，悬赏板）：清剿森林狼 ×3
- q_d_herb（D，悬赏板）：采集雾绒草 ×3（采药点事件获得）
- q_c_escort（C，世界偶遇）：林间空地遇受困的青芷 → 护送至猎户小屋（途中固定两波战斗）
- q_c_wolfking（C，猎户小屋告示）：讨伐狼王灰鬃（废弃哨塔，精英战）

## 隐藏地点：月光苔洞窟

- 解锁：迷雾深处累计触发 2 次"月光苔微光"事件，或完成 q_d_child 后由小荞指路。
- 内容：洞壁覆满月光苔，夜里整洞如浸在淡青色月光里。可采集月光苔（稀有药剂材料，高价）；发现日志重要条目；布罗迪若同行会触发特殊对话（他找了这种苔七年）。
- 氛围：这是 MVP 第一个"远方感落进手心"的时刻——森林里真的藏着值得走这一趟的东西。

## 氛围描写基准（供 LLM 演绎）

雾是这片森林的性格。写雾帷森林时，先写光（被雾滤软的光），再写声（忽远忽近的声），最后才写看见了什么。战斗要短促——雾里的威胁来得快，去得也快。扎营时，篝火的光圈是整个世界。
