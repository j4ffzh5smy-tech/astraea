# 阿斯特雷亚世界圣经（冻结版 v1.0）

> 本文件为世界设定的唯一事实来源。LLM 只能在本文档既定设定内演绎，禁止即兴创造新的地理、势力、历史、魔法规则与龙的具体信息。凡本文档未写明之事，LLM 应以"无人知晓""传闻不一"处理，不得编造为事实。

## 一、大陆与纪元

大陆「阿斯特雷亚」，魔法纪元 743 年。

世界的中心曾是世界树「尤克特拉」。它不是神话修辞，而是一棵真实存在过的、根系贯穿整片大陆的巨树——大陆的魔力曾顺着它的根须均匀流淌，风调雨顺，魔物稀少。

七十二年前（纪元 671 年），尤克特拉在一夜之间枯死。没有人知道原因。树冠化作的灰烬下了整整一个月，落在哪儿，哪儿的野草就疯长到齐腰。

从那以后，魔力开始"紊流"：有的地方浓得让石头悬浮，有的地方稀薄到法师点不亮一根蜡烛。紊流催生出越来越多的魔物。而最深远的变故是——沉眠于大地各处的龙族，陆续醒了。

**龙的规则（冻结）**：
- 龙真实存在，但 MVP 阶段没有任何人见过龙的活体。龙只以痕迹出现：焦土、爪印、鳞片、迁徙的兽群、彻夜不熄的天边红光。
- 龙的活动范围在缓慢扩大。靠近龙眠荒原的边境村落已开始迁址，流民沿路向西。这是世界的长线压力，也是"为什么满世界都有事发生"的根本理由。
- 禁止 LLM 让龙正式登场、被杀、被驯服或与玩家对话。龙是远方的雷声，不是眼前的敌人。

## 二、势力

### 王都「圣辉城」
大陆的心脏，魔法帝与八大骑士团驻地。白墙的城邦建在尤克特拉枯死的根盘之上，八座尖塔各属一个骑士团。
- **准入规则（冻结）**：圣辉城前期不可进入。入城大道设有关卡「辉门」，查验身份纹章——只有贵族、注册骑士、行会使者与持有王都通行令者可入。玩家在前期没有任何合法身份，辉门卫兵会礼貌而坚决地拒绝。
- 圣辉城必须"活在所有人的嘴里"：商人谈论它的物价，骑士谈论它的选拔，流民谈论它的城墙是否挡得住龙。它是所有人心中"真正的地方"。
- 八大骑士团：辉光、银棘、风暴、灰烬、深泉、磐石、夜鸦、蔷薇。MVP 只许提及名字与模糊传闻，不得展开内部设定。

### 自由赏金公会「铜壶」
起源于烬炉镇酒馆「铜壶与龙息」二楼的民间组织，如今在十几个城镇设有联络点。不收会费，认契约不认人。
- 声望等阶（冻结）：无名小卒 → 注册猎人 → 铜牌猎人 → 银牌猎人 → 金牌猎人 → 传奇。
- 公会不是官方机构，王都视其为"有用的麻烦"。

### 黑市「灰烬会」
盘踞在熔痕裂谷地下网络的走私者结社，倒卖龙骸碎片、禁术卷轴与来路不明的魔导器。
- **MVP 只做传闻铺垫**：NPC 可以压低声音提起它，矿工可以发誓见过它的标记，但玩家无法接触、无法加入、没有相关系统。它是"世界比玩家大"的证据。

## 三、地理

### 历史地层（v0.5 新增：世界的过去不止一层）

- **纪元 671 年（72 年前）**：尤克特拉枯死，魔力紊流开始。
- **纪元 703 年（40 年前）· 西境战争**：西境兽人部落在"碎牙可汗"率领下东进，王国沿雷鸣山脉筑哨塔链御敌。战争打了六年，以兽人内乱退兵告终。雾帷森林里的废弃哨塔、山口下的西林哨所，都是那场战争的遗物。战后王国裁撤边军——许多老兵成了第一批赏金猎人，这是铜壶公会的源头。
- **纪元 728 年（15 年前）· 镜湖大静水**：一夜之间，镜湖方圆三十里所有声音消失，持续九天。没人解释得了，镜湖人自己绝口不提。此后吟游诗人开始成批离开故乡。
- 写法准则：旧遗迹对应当年的事件（哨塔、老兵、军械库），新麻烦对应当下的紊流（魔物、龙迹、流民）——两层历史互为注脚。

### MVP 开放区域（5 区）

**烬炉镇**（边境小镇，玩家的家）
- 位于大陆东南边境，因镇西的老铁匠铺终年炉火不熄得名。常住人口不足三百。
- 地标：酒馆「铜壶与龙息」（老板娘玛尔塔）、铁匠铺（布洛姆）、杂货店（艾达）、公会联络点（酒馆二楼，接待员芬恩）、悬赏板（酒馆门旁）。
- 气质：疲惫但温厚。这里是"世界的边角料"，也是被龙的消息最先波及的边镇之一。

**雾帷森林**（危险度 D/C）
- 烬炉镇以北半日路程的古老林地，终年轻雾。雾不是魔法，是尤克特拉死后水汽失了管束。
- 内容：森林狼群、雾行蛛、迷路事件、猎户小屋（野外落脚点，老猎户加洛）、药剂师的采药小径、隐藏地点「月光苔洞窟」。

**熔痕裂谷**（危险度 C/B）
- 烬炉镇以东一日路程的大地热伤，一道深不见底的裂口，岩浆在谷底缓慢流淌。
- 内容：火属性魔物、火纹矿石、矿工营地（野外落脚点，矿工头子黛拉）、灰烬会传闻、隐藏地点「龙鳞岩台」。

**雷鸣山口**（危险度 C，v0.5 新增）
- 烬炉镇西北的越岭通道，雾帷森林北缘再上行半日。因终年雷暴得名——紊流把雷电钉在了山脊上。
- 内容：雷鹰、山魈、雷音栈道、风暴神龛（旧战争时期的祭祀所）、通往圣辉城的官方山道起点。
- 气质：危险但壮丽。在这里第一次能望见圣辉城的尖塔（比地图上远，比想象里近）。

**西林哨所**（危险度安全区，v0.5 新增）
- 烬炉镇以西的旧军营，西境战争的遗物，如今是半军半民的落脚点，收容西迁的流民与退伍老兵。
- 内容：百夫长卫霜（退役骑士）、军需官佟石、流民营、旧军械库（上锁，传说里锁着当年的东西）。
- 功能：第二个"类家"据点——告示板、基础补给、流民线八卦。气质：体面地衰败着，规矩比人多。

### 只闻其名（冻结，不可进入）

- **龙眠荒原**（S 级）：大陆东北的焦土，龙族苏醒的中心。地图上是一片骷髅标记。任何人劝阻玩家前往都是合理的。
- **镜湖**：大陆中部的巨大湖泊，湖水清澈得能照见"人心里的事"。吟游诗人的故乡。所有关于镜湖的描述必须带一层不真实感。
- **圣辉城**：见势力节。地图上可见八座尖塔，叙事中高频出现，前期不可进入。
- **白帆城**（v0.5 新增）：大陆西南的自由港，不属于任何王国，商船与走私船共用一片锚地。烬炉镇商路的货源地。传闻里"什么都能买到，包括不该问的"。
- **风语草原**（v0.5 新增）：西部高原上的无垠草场，风掠过时整片草原像在低语。游牧部族的故乡，盛产战马与星象师。兽人战争的古战场之一。
- **灰潮沼泽**（v0.5 新增）：南部的死亡沼泽，尤克特拉的一条主根烂在这里，灰白色的水潮按无人理解的规律涨落。进去的人要么空手而归，要么不归。
- **苍岩王陵**（v0.5 新增）：北方群山中前朝王室的陵寝群，石椁嵌在整面山壁上。官方说法是有骑士团驻守护陵，实际上十年没人换过岗了。

## 四、魔法规则（冻结）

1. **魔导书**：每个觉醒者生来绑定一本魔导书，无实体时以烙印形式存在于左手手背，唤出时化为书页。每人仅有一本，不可更换、不可剥夺（人死书散）。
2. **主属性**：魔导书在觉醒时定下主属性，决定此人一生魔法的大方向。已知属性：火、水、风、土、雷、暗、治愈、具现。（v0.4.1 起：开局八属性全部开放，由玩家自由选择，每属性 4 页技能。）
3. **翻页**：技能以"书页"形式逐页解锁。变强的本质是让魔导书"愿意为你翻开新的一页"——实战、生死之间、强烈的情感都可能成为翻页契机。（引擎层面以等级门槛实现，叙事层面以"翻页"演绎。）
4. **法力**：施法消耗法力，法力枯竭强行施法会反噬自身。魔力紊流区施法效果不稳定（叙事素材，MVP 无数值效果）。
5. **禁止事项**：不存在复活术、时间魔法、传送魔法（MVP 阶段）。任何人声称会这些，都是骗子或传闻。

## 五、种族与众生

- 人类为主体。矮人擅锻造与药剂，寿命约两百年，性格公认的话多。精灵避世，MVP 不登场，只可被提及。兽人生活在更远的西境，是流民传闻里的常客。
- 魔物：尤克特拉死后魔力紊流的产物，由野兽异变或纯粹由淤积魔力凝结而成。没有智慧魔物文明（MVP），魔物是威胁，不是种族。

## 六、基调与叙事准则

1. 这是一个"伤痕累累但值得生活"的世界。人们谈论龙，也谈论今年的麦价和隔壁的婚礼。
2. NPC 有自己的生活：他们会忙、会拒绝、会误解玩家、会在玩家不在时继续过自己的日子。
3. 远方感是第一生产力：永远有比玩家当前处境更大的事在发生，玩家是从世界的边角一点点听说它的。
4. 幽默允许存在，但不许消解世界的重量。布罗迪的碎嘴可以逗乐，但他等的那个不会回来的人是真的。
5. 禁止打破第四面墙，禁止现代梗，禁止 LLM 以旁白身份剧透玩家不该知道的事。
