# 魔导纪元 · Astraea（v0.7）

单人 AI 文字开放世界 RPG，纯前端单页应用，无需安装任何东西。

## 怎么玩

双击 `index.html` 即可开始游戏（推荐 Chrome / Edge）。

- **存档**：自动保存在浏览器 localStorage，每回合结算后自动写入；游戏内「设置 → 导出存档文件」可把存档下载为 JSON，换浏览器/换电脑时用「导入存档文件」恢复。
- **注意**：存档跟着"打开方式"走——双击文件打开（file://）和用预览服务打开是两个存档，请固定一种方式。
- **全屏**：顶栏最右侧的展开图标可切换全屏游玩（Esc 退出）。
- **场景画幅**：叙事窗上方是场景画——酒馆、五片区域各有专属绘卷，走到哪里画到哪里。
- **时段与天气**：移动与探索会推进时段（清晨/白日/黄昏/夜晚），睡觉与扎营回到清晨；时段与天气一起影响 AI 叙事的心境基调。
- **装备与锻造**：侧栏有武器/护甲两个装备槽；狩猎采集攒材料，到烬炉镇广场找布洛姆按配方打造（狼皮甲、火纹剑、惊雷剑、龙鳞护符），背包里点「装备」上身。
- **精英委托**：狼王/火元素/魈王改为三段式——到场调查两条线索，备齐剑油与捕兽夹后由你主动发起猎杀（战前道具：猎魔剑油增伤、捕兽夹废掉敌方反击）。
- **地区声望**：交付委托会累积当地声望——熔岭 ≥10 黛拉半价供货；西境 ≥15 卫霜开放私藏军械。
- **道德岔路**：逃兵阿七（雷鸣山口）——军法还是人情，你选，世界会记得。
- **龙骰**：酒馆新增赌桌，三颗骨骰三局两胜；赢满十场，玛尔塔有句话说给你听。
- **魔物图鉴**：发现日志里的魔物升级为图鉴卡——讨伐数、弱点、生态、战利品。
- **地图**：顶栏「地图」打开大陆舆图，点选金色地名进入该区域的**小地图**（图标标注关键地点与功能；隐藏地点发现后补上）。
- **世界观 / 人物卡**：顶栏两个入口——编年史式世界观（年表/势力/禁区/魔导书）与按地区/同伴分类的人物图鉴（交谈过后解锁）。
- **旅人电台**：进游戏自动随机开播（需联网）；点喇叭图标管理曲目。
- **名词信息卡**：叙事文本里金色虚线下划线的人名/地名/名词可点击，弹出信息卡。
- **AI 叙事**：「设置」页填入 OpenAI 兼容 API（Base URL + Key + 模型）即可切换为 LLM 叙事（导演模式：心境基调 + 近期事件回望 + 文风约束）；不填则为内置离线叙事器，零成本游玩。

## 文件结构（供 Kimi Code 修改）

```
WY/
  index.html        入口 + 全部界面（UI、样式、面板、电台、龙骰、锻造、词条卡都在这一个文件里）
  bundle.js         打包产物（world/ + data/ 的内容合集，勿手改）
  build.mjs         打包脚本：改了 world/ 或 data/ 后运行 `node build.mjs` 重新生成 bundle.js
  engine/           游戏引擎（改规则改这里）
    state.js        硬状态、数值、背包、装备槽、地区声望、时段、近期事件、存档读写与旧档迁移
    rules.js        变更校验白名单、战斗结算（武器/护甲/剑油/捕兽夹）、补给消耗、区域锁
    llm.js          LLM API 适配、导演模式 prompt 组装、JSON 容错、离线文本解析
    game.js         编排层：世界图（5 区域 22 节点）、动作、探索、委托、精英三段式、道德岔路、锻造配方、龙骰结算
  world/            世界设定（改剧情改这里）
    bible.md        世界圣经（冻结设定，LLM 不可改写）+ 历史地层
    regions/*.md    区域内容包（烬炉镇 / 雾帷森林 / 熔痕裂谷 / 雷鸣山口 / 西林哨所）
  data/             结构化内容（改数值改这里）
    quests.json     委托：6 章主线（series:main，auto 自动完成）+ 14 支线（含逃兵道德岔路）+ 悬赏板模板
    grimoires.json  8 属性魔导书 × 4 技能、克制表
    monsters.json   怪物数值 + 弱点 + 生态 + 战利品掉落
    npcs.json       NPC 台词（顺序消耗制）+ 人物小传 + 3 位同伴的篝火/探索事件
    rumors.json     八卦传闻表
    ambient_events.json  各区域环境事件表 + 营地事件表
    items.json      物品（含战前道具、素材、可锻造装备）
    lexicon.json    名词词条库（23 条，叙事内可点击弹卡）
  assets/           标题页背景图、大陆舆图、5 张区域小地图、6 张场景绘卷（AI 生成）
  test/             验收测试（node test/acceptance.test.mjs / playthrough.test.mjs）
  游戏设计总方案.md   ★ 总体设计 + 满意/需修改标注（审阅用，先读这份）
  演进路线提案-v0.7.md v0.7 全部提案（A–H，已全数落地）
  设计打磨-v0.4.md   设计定案（数值、契约、变更记录）
```

## 分享给朋友

两种方式：

1. **打包文件夹**：把整个 WY 文件夹压缩成 zip 发给朋友，对方解压后双击 `index.html` 即玩。无需安装任何东西；存档在各自浏览器里互不影响。旅人电台需要联网。
2. **在线链接**：已发布为在线网址，朋友点开直接玩（手机浏览器也行）。注意：在线版是发布时的快照，本地更新后需要重新发布朋友才能看到新版。

注意：API Key 存在你自己的浏览器里，不会随文件或链接泄露给朋友——朋友想用自己的 Key 需在设置页自填；不填就是免费的离线叙事模式。
